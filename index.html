Один дневник на всех устройствах

Подключение…

Сначала на телефоне, где видны записи: нажми «Привязать этот дневник к Google». Затем на компьютере войди в тот же Google-аккаунт.
Перед первой привязкой можно сохранить JSON-копию ниже. Привязка сохраняет текущий дневник.

После сохранения на другом устройстве нажми «Обновить данные», чтобы получить последние записи.

Отчёт для врача

Отдельный печатный документ: карта тела, график боли, препараты, активность, цикл и подробные записи.

Для PDF: открой отчёт → «Печать / сохранить в PDF». Имя и вопрос используются только для отчёта и не записываются в Firebase.

Скачать

Если файл не скачивается, скопируй весь текст и сохрани его в файл с расширением .json.

JSON содержит все записи и настройки цикла. CSV содержит записи, включая цикл и заметки. Файлы содержат личные данные.

Восстановить из JSON

Перед записью появится состав файла. Импорт добавляет отсутствующие записи, не удаляя существующие. Настройки цикла восстанавливаются из файла.
