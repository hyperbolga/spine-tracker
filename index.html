Данные и резервная копия
Скачать

Если файл не скачивается, скопируй весь текст и сохрани его в файл с расширением .json.

JSON содержит все записи и настройки цикла. CSV содержит записи, включая цикл и заметки. Файлы содержат личные данные.

Восстановить из JSON

Перед записью появится состав файла. Импорт добавляет отсутствующие записи, не удаляя существующие. Настройки цикла восстанавливаются из файла.
